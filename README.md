# GitHub Pages Favicon Test

This repository hosts a controlled page for authorized favicon and metadata validation.

Expected public URLs:

- `https://salahlouffidi.github.io/`
- `https://salahlouffidi.github.io/favicon.svg`
- `https://salahlouffidi.github.io/favicon.png`
- `https://salahlouffidi.github.io/favicon.ico`

A successful fetch of the favicon from a target endpoint proves remote favicon retrieval, but it does not prove SSRF impact by itself.
